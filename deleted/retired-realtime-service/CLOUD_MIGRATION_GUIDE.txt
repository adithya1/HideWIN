=========================================================
      HIDE-WIN CLOUD MIGRATION & VPC DEPLOYMENT GUIDE
=========================================================

This folder ("hidewin-cloud-relay") is a completely standalone microservice. 
Right now, you are running it locally on your PC (Port 9000) and using a Reverse Tunnel (start_tunnel.bat) to bypass your community Wi-Fi router.

When you purchase a real Cloud VPS (like AWS EC2, DigitalOcean, or Linode) and want to deploy this to production, follow these exact steps:

---------------------------------------------------------
PHASE 1: DISCONNECTING THE LOCAL TUNNEL BYPASS
---------------------------------------------------------
When you are ready to move to the cloud, you must stop the local workaround:
1. Close the command prompt window running `start_tunnel.bat`.
2. Run `stop_cloud_relay.bat` to kill the local port 9000 server.
3. Open your Hide-WIN Desktop App.
4. Go to the Admin Dashboard (Settings) and change your DNS IP from the temporary `hidewin.loca.lt` back to your real domain (e.g., `hidewin.com` or `api.hidewin.com`).

---------------------------------------------------------
PHASE 2: DEPLOYING THIS MICROSERVICE TO YOUR CLOUD VPC
---------------------------------------------------------
Because we cleanly separated this folder, deployment is incredibly easy:
1. Zip up this entire `hidewin-cloud-relay` folder.
2. Upload the zip file to your Cloud VPS via SSH/SFTP and unzip it.
3. Ensure Python and Uvicorn are installed on your Cloud Server:
   $ pip install fastapi uvicorn
4. Run the Cloud Relay on your server (usually on port 80 or 443 in production):
   $ uvicorn cloud_relay:app --host 0.0.0.0 --port 80

---------------------------------------------------------
PHASE 3: CONFIGURING YOUR DESKTOP APP FOR PRODUCTION
---------------------------------------------------------
Your Desktop App is currently hardcoded to connect its outbound tunnel to `127.0.0.1:9000` (which is why it works locally right now). 
Once your cloud server is live:
1. Open `Hide-Win-Master\src\components\views\InviteView.js`.
2. Find the line: `const cloudHost = (this.dnsIP && this.dnsIP.includes('.loca.lt')) ? this.dnsIP : '127.0.0.1:9000';`
3. Change `'127.0.0.1:9000'` to your actual Cloud VPC IP or Domain (e.g., `'hidewin.com:80'`).
4. Restart your Desktop App.

Your Desktop App will now securely tunnel outbound to your real Cloud VPC. Guests will visit your real website to join the room, and the Cloud VPC will seamlessly bridge the WebRTC connection back to your PC!
