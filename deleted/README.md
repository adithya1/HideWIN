# Reversibly archived files

Files here were moved out of active project paths, not permanently deleted. Restore a file or folder to its original location if future work needs it.

- `meeting-invites/`: removed invitation API and reminder implementation files.
- `legacy-agent-patches/`: historical one-off patch scripts with no build, CI, or runtime callers.
- `desktop-maintenance-history/`: one-off UI patchers, temporary copies, diffs, snippets, and generated logs from the desktop app root.
- `transcription-patch-scripts/`: one-off server patch scripts; the transcription service itself remains active.
- `root-patch-scripts/`: one-off repository environment patch script.
- `placeholder-load-tests/`: nonfunctional load-test scaffolds that only simulated work and did not exercise WebRTC or HTTP endpoints.
- `old-log-artifacts/`: old local test logs.
- `meeting-management/`: desktop and web meeting screens, guest join page, meeting CRUD APIs, calendar webhooks, mock calendar endpoints, and meeting-only calendar event sync implementations.
- `retired-realtime-service/`: meeting-room WebRTC signaling relay and its launch/configuration files.
