# AI Usage Log

This document records the use of AI tools during the development of HideWin.

1. **Google Antigravity (AGY)**: Used as an agentic coding assistant to debug mobile responsive views, fix LitElement template syntax errors, and restore corrupted codebase states.
2. **Gemini 2.0 Flash**: Integrated directly into the application as the core intelligence engine for analyzing screen content and providing contextual interview/meeting assistance.
3. **Cursor / GitHub Copilot**: Utilized for standard boilerplate generation and inline code completion during the UI development phase.
