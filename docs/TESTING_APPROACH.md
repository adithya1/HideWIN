# Testing Approach

1. **Unit Testing**: Testing individual utility functions and LitElement properties.
2. **Integration Testing**: Verifying IPC communication between the main process (Electron) and renderer processes.
3. **Manual UI/UX Testing**: Ensuring the responsive layout correctly switches between Desktop and Mobile/Tablet views without breaking the "Pill Bar".
4. **End-to-End**: Simulating a full interview session with mock audio/video input.
