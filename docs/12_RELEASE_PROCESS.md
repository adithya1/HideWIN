# 12 - Release Process

When preparing for a release, always follow the "Kid-Friendly" Release Note format in `RELEASE_NOTES.md`.

It must include:
1. 🌟 What is new?
2. 🔧 What changed?
3. 🧪 What did we test?
4. 🛡️ Did we check old features?
5. 🐛 What did we fix?

This ensures that Developers, Testers, Managers, and Non-Technical Stakeholders can all understand the release instantly.
