# Demo Guide

To demonstrate HideWin:

1. Launch the application using \
pm start\.
2. Input a valid Gemini API Key in the settings.
3. From the MainView, select "Interview" profile.
4. Click "Start Session".
5. Observe the transparent Live Bar appear at the top of the screen.
6. Open a mock interview video or document; HideWin will analyze the screen context and provide responses.
