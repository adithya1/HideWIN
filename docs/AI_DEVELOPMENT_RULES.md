# AI DEVELOPMENT RULES
Before modifying any code:
1. Understand the existing module.
2. Identify related functionality.
3. Do not overwrite unrelated code.
4. Preserve existing APIs.
5. Add docstrings.
6. Add unit tests.
7. Add negative tests.
8. Run existing regression tests.
9. Update documentation.
10. Update release notes.

Important rule: NO FEATURE IS COMPLETE UNTIL TESTS PASS.
