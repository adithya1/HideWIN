# HIDE-WIN DEVELOPMENT CONTRACT

Every code change must:
1. Have a clear purpose.
2. Have a meaningful Git commit message.
3. Include tests.
4. Include negative tests where applicable.
5. Include regression testing.
6. Preserve existing functionality.
7. Include documentation updates.
8. Include release note updates.
9. Pass local tests.
10. Pass GitHub Actions CI.

No feature is complete only because the code works. A feature is complete when:
CODE + TESTS + REGRESSION + DOCUMENTATION + CI are complete.
